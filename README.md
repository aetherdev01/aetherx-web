# AetherX Web

Modern Vite + React website for the AetherX Android performance app.

## Pages

- `/` Home
- `/download` Download
- `/preview` Preview
- `/about` About

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The project uses inline SVG icons and does not depend on an icon package.
